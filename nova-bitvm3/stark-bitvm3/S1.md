# S1: finalized-circuit lowering

This stage imports the ten gate families from the pinned upstream `circuits::Circuit` into a Boolean constraint checker. It accepts a witness only when every field word is canonical, all gates hold, and every constant and public output agrees with the caller's trusted policy. The graph itself is trusted code/configuration; a prover-chosen graph or policy is outside the interface's security contract.

The importer takes `FinalizedContext`, requires completion of guessed-variable finalization, and destructures all upstream Circuit fields exhaustively. It imports the finalized domain constraints and all constants. Output markers need a corresponding fixed expected value. The generator u, zero and one are explicitly pinned even for hand-built circuits.

Permutation constraints are checked by deterministic bitonic sorting, including multiplicities and padding for non-power-of-two lengths. Packed u32 operations constrain both 16-bit limbs and both zero extension limbs. Program shape and permutation-work limits are checked before Boolean construction.

The `upstream` crate compiles the pinned upstream native field/gate code. It deliberately excludes Stwo's prover feature. The native comparisons use synthetic all-gate circuits and upstream's own finalizer. A complete STARK verification circuit and authentic Shinigami proof are still separate milestones. This stage introduces a witness for the circuit's internal values, whose validity is checked inside the Boolean relation.

Pending verification: the S1 code has been submitted to bounded CPU CI. Results are recorded separately after the checks finish.
